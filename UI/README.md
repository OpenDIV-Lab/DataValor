# DataValor UI

DataValor 全链路本地工作台。直接打开 `index.html` 可使用离线工作流演示；要调用仓库中的真实 Python 算法，运行：

从仓库根目录启动（推荐）：

```bash
python -m UI.run --port 8080
```

也可以从 `UI/` 目录执行 `python run.py --port 8080`。启动器始终依据
`run.py` 的实际位置解析仓库根目录和 `src/`，因此两种写法使用同一套导入路径，
不再依赖当前工作目录或手工设置 `PYTHONPATH`。

页面支持：

- 任意增加、删除和重复添加相同类型的环节；
- 从输出端拖至输入端建立数据流，双击连线或在右栏删除连接；
- 从环节输入端拖至画布空白，建立可配置 URI、格式、Schema 和内联内容的手动起始数据；
- 按环节约束校验输入数量和输入类型，无输入、超量或类型不兼容时标红；
- 多输入环节根据连接分别显示数据类型，手动输入可从目标支持的类型中切换；
- 环节启停、内部组分启停、实现选择、参数配置和场景预设；
- 在节点输出端或右侧详情中下载该环节的输出占位产物描述；
- 浏览器自动保存以及完整工作流 JSON 导入导出。
- 使用滚轮或工具栏缩放整个画布，并按住空白背景拖动画布；
- 按住 Shift 在背景拖动进行框选，随后可整体移动、启停或删除多个环节；
- 在右侧为选中环节配置超时、重试、缓存和输出格式，并运行当前环节；
- 运行时读取全部 incoming 内容，生成模块语义输出，更新 outgoing 连线、运行记录和产物中心；
- 点击连线查看来源、目标、类型、更新时间和当前内容，并可人工修改后供下游读取；
- 数据产品目录可创建产品并一键放入画布，运行记录和产物中心提供真实的当前工作区内容。
- 添加环节区域以悬浮信息展示模块职责，画布节点只保留名称、输入输出和运行状态；
- 下方详情面板独立滚动，为算法选项、输入、运行参数和后续扩展保留更大空间；
- 起始数据支持直接内容、URI/文件、表格记录和键值参数模式，并配置格式、编码、分隔符与 Schema；
- DataPrice 和 DataMarket 支持多买方、多卖方、预算、出价、保留价、要价、数量及双边市场、竞争采购和多买方拍卖模板。

UI 配置使用 `datavalor.ui-workflow/v1alpha1`，不修改 Python 侧已有接口；后续可在适配层映射为现有 `PipelineSpec` 或 workflow 配置。

当前静态页面中的“运行”是确定性的浏览器端模块语义执行器，用于编排验证、数据传递和交互演示，不会在浏览器里直接启动 Python。接入服务部署时，可以保持相同输入、输出和运行记录结构，将 `executeModule` 替换为调用 DataValor Python runner 的 API。

通过 `UI.run` 启动后，治理、画像、质量评估和估值页面调用真实 DataValor 实现；组件目录从所有 registry 动态读取，外部能力页面展示当前环境中的可用状态。数据产品、运行记录和产物持久化在 `UI/workspace/`。

## 复杂输入与市场工作台

“数据产品”页面中的创建工作区支持 JSON、JSON Lines、CSV、TSV、键值参数、
本地文本文件、URI/HTTP/对象存储引用、已登记产品、历史产物和上游输出引用。
解析步骤会返回标准化记录、推断 Schema、记录/字段统计以及可定位到行或字段的错误；
输入方式和解析参数保存在产品的 `metadata.input_config` 中。

“定价与市场”仍是一个左侧导航模块，其内部按“场景、产品与输入、参与方与订单、
定价合同、市场机制、执行过程、结果与诊断”组织。定价模型和市场机制的参数表单由
`GET /api/workbench/schemas` 返回的实际能力生成，不显示仓库中不存在的占位方法。

在线模式支持多产品选择、JSON/JSONL/CSV 批量订单、AND/XOR 组合需求、多单位统一价、
预算/质量感知采购和多属性匹配。执行结果同时包含报价分量或市场分配，以及标准化、
校验、清算和诊断 Trace；诊断覆盖机制性质、收入对账、供需缺口、供需分群、市场健康
和异常信号。旧的单产品 `product_id` 请求继续有效，多产品市场请求使用：

```json
{
  "product_ids": ["retail-demand", "weather-stream"],
  "parameters": {
    "mechanism": "bundle_matching",
    "budget": 200000,
    "bids": [
      {
        "buyer_id": "buyer-a",
        "product_ids": ["retail-demand", "weather-stream"],
        "amount": 180000,
        "constraints": {"bundle_mode": "and"}
      }
    ],
    "asks": []
  }
}
```
